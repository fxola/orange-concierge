# Client Evidence Collection Standard

Purpose: define the minimum non-secret evidence required before Orange Concierge makes custody, security, or planning recommendations.

## Use When

- A consultant is preparing an assessment from meeting notes.
- A reviewer needs to verify that a recommendation is grounded.
- A client describes current operations but has not provided supporting details.

## Minimum Evidence

- Current custody arrangement in the client's own words.
- Named operational concern or goal.
- Security posture signals such as device hygiene, phishing exposure, or incident history.
- Planning signals such as successor access, estate coordination, or family governance.

## Evidence Rules

- Do not request seed words, private keys, recovery codes, passwords, or API key values.
- Ask for process descriptions, policy names, dates, and roles instead of secrets.
- Record direct quotes only when they support a concrete fact.
- Prefer short quotes that prove one fact at a time.

## Review Standard

A recommendation is not ready for review unless it cites both client evidence and internal guidance. If the evidence is missing, recommend evidence collection before operational changes.
